# eFood — Exercício M37

Projeto independente do exercício M37 da EBAC.

## Requisitos atendidos

- React
- Styled Components
- React Router
- conteúdo carregado pela API oficial da EBAC
- modal de produto
- Redux Toolkit
- React Redux
- carrinho lateral
- inclusão de produtos no carrinho
- remoção de produtos
- contador de produtos
- total da compra calculado automaticamente
- preparado para Vercel

## API

`https://api-ebac.vercel.app/api/efood/restaurantes`

## Executar

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Vercel

- Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
